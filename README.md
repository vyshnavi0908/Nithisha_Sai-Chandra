# Royal Wedding Scroll

Act as an award-winning UI/UX designer and senior frontend developer with expertise in creating luxury wedding websites.

Design and develop a premium single-page Indian wedding invitation website that looks like an expensive handcrafted royal Hindu wedding invitation card.

IMPORTANT:

Do NOT create a modern minimal website.

Do NOT use generic wedding templates.

The design should match traditional Indian wedding invitation cards with royal aesthetics, temple-inspired decorations, luxurious gold ornaments, and rich cultural details.

The entire website should make visitors immediately feel they are entering a grand Hindu wedding celebration.

QUALITY

The website should look like a ₹1 lakh custom wedding website made by a luxury design studio.

The experience should feel cinematic, emotional, elegant, premium, traditional, and immersive.

The user should feel like they have entered a royal palace wedding invitation rather than a normal website.

Avoid any modern corporate UI. Every section must resemble an ornate handcrafted Indian wedding invitation with luxurious floral decorations and temple-inspired artwork.Use a portrait invitation layout adapted into a scrolling website.

Each section should appear as a separate invitation page with ornate gold borders and cream textured paper.

Decorative elements should remain symmetrical, with matching floral arrangements, lamps, and ornaments on both sides.

Prefer illustrated motifs (Ganesha, lotuses, mandalas, temple arches, bells) over photographic decorations.

Maintain generous spacing and elegant typography so every section feels like turning to the next page of a premium printed invitation.
